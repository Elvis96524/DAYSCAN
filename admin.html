Scanner 账号管理

只有你能让账号生效：这里生成 users.json，只有你把它上传到自己的 GitHub 仓库，别人才能用这些账号登录。别人打开这个页面也无法替你发布。

1. 载入现有账号（可选）

2. 添加账号 / 重设密码

密码会显示在屏幕上，请在添加后马上告诉对方；页面不会保存明文。用户名已存在时，会替换成新密码。

3. 当前账号

4. 下载并上传到 GitHub

  1. 打开你的 GitHub 仓库 → Add file → Upload files。
  2. 把下载的 users.json 拖进去（文件名必须是 users.json，会替换旧的）→ Commit changes。
  3. 等 1–2 分钟，用户重新打开应用就能用新账号；被删除的用户或改了密码的用户，回到页面时会被退出。

仓库是公开的，users.json 里的用户名和加密后的密码任何人都能看到。加密能挡住随手猜，但挡不住对弱密码的离线破解，所以请用长密码（随机生成的最好）。
